# VetCare
VetCare – Veteriner Klinik ve Hasta Takip Sistemi

VetCare, veteriner kliniklerinin hizmetlerini, veteriner hekimlerini, evcil hayvanları ve randevu süreçlerini dijital ortamda yönetmelerini sağlayan ASP.NET Core MVC tabanlı bir web uygulamasıdır.

Sistem sayesinde hayvan sahipleri üye olabilir, evcil hayvanlarını kaydedebilir, veteriner hekimlerden randevu alabilir ve hayvanlarının aşı geçmişini takip edebilir. Veteriner hekimler randevuları yönetebilir, onaylayabilir veya reddedebilir ve muayene notları ekleyebilir. Admin kullanıcıları ise sistemin genel yönetimini gerçekleştirebilir.

Proje kapsamında ASP.NET Core MVC, C#, Entity Framework Core, ASP.NET Core Identity, REST API ve Model Context Protocol (MCP) teknolojileri kullanılacaktır. Ayrıca LINQ sorguları ve rol bazlı yetkilendirme ile güvenli ve işlevsel bir sistem geliştirilmesi hedeflenmektedir.
